# ☕ Coffee Shop Sales Dashboard — Excel

An interactive Excel dashboard analyzing 6 months of sales data across 3 New York coffee shop locations.

---

## 📊 Dashboard Preview

![Coffee Shop Sales Dashboard](Coffee%20Shop%20Sales%20Dashboard.png)

---

## 🔍 Key Insights

- **Total Revenue:** $698,812 across 149,116 customer visits
- **Peak Hours:** Orders spike between 8–10 AM (morning rush)
- **Top Location:** Hell's Kitchen leads with $236,511 in sales
- **Best-Selling Product:** Barista Espresso at $91,406
- **Busiest Day:** Friday (21,654 orders)
- **Top Category:** Coffee (39% of all sales)

## ⚙️ Features

- **Interactive Slicers** — Filter by Month (Jan–Jun) and Day of Week
- **KPI Cards** — Total Sales, Footfall, Avg Bill/Person, Avg Order Value
- **6 Charts** — Hourly trends, category breakdown, location comparison, top products, weekday analysis, size distribution
- **Pivot Tables** — Underlying all charts for clean, dynamic data

## 🛠️ Tools Used

- Microsoft Excel (Pivot Tables, Slicers, Charts, Conditional Formatting)
